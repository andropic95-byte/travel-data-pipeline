# Travel Data Pipeline

Учебный проект пакетной обработки событий бронирований: загрузка JSONL, контроль качества, обновление данных в SQLite и SQL-отчёт. Данные синтетические и не связаны с внутренними данными Aviasales.

## Поток данных

JSONL с событиями бронирований → проверки полей и бизнес-правил → SQLite с обновлением по booking_id и updated_at → SQL-агрегация по дню, маршруту и валюте → CSV-отчёт.

Некорректные записи попадают в quarantine-файл с номером строки и причиной. Для каждого запуска сохраняются счётчики полученных, новых, обновлённых, повторных и отклонённых записей. Суммы хранятся целыми единицами минимальной денежной величины; разные валюты не суммируются вместе.

## Запуск

Нужен Python 3.11 или новее. Дополнительные библиотеки не требуются. Выполняйте команды из папки проекта:

```powershell
python pipeline.py bookings.jsonl
```

Повторная загрузка той же партии:

```powershell
python pipeline.py bookings.jsonl
```

Количество бронирований в базе не увеличивается от повторных событий. Это идемпотентность состояния bookings; журнал запусков и quarantine-файлы намеренно пополняются. При двух событиях с одинаковым ID и временем сохраняется первое принятое состояние. Более старая версия не перезаписывает новую.

## Проверки качества

- ID бронирования обязателен и имеет допустимый формат.
- Коды отправления и назначения состоят из трёх букв и отличаются.
- Поддерживаются состояния confirmed/cancelled и валюты RUB/USD/EUR.
- Цена конечная, неотрицательная, не выше заданного учебного ограничения; максимум два знака после запятой.
- Даты имеют допустимый формат, время обновления содержит часовой пояс.
- Вылет и обновление не предшествуют дате бронирования.

## Ограничения

Это небольшой batch-пайплайн на синтетических данных. Нет Spark, Airflow, Trino, Kafka, AWS, Kubernetes, распределённой обработки, настоящего стриминга и гарантии exactly-once. Файлы отчёта создаются после коммита базы и не входят в одну транзакцию с ней. Повреждённые данные сохраняются локально без шифрования — используйте только учебные записи.
